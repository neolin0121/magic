# Neo 魔石配裝器

功能：魔石資料庫、我的魔石、收藏、自動最佳化、迅擊/馭傷/強襲切換、手機版、localStorage 自動存檔、JSON 匯入/匯出。

## Vercel
把此資料夾上傳 GitHub，再到 Vercel 匯入該 Repository。Framework Preset 選 Other，不需要 Build Command，直接 Deploy。

## 2026-08-13 潛能更新
- 新增「同印契合」。
- 效果：每裝備 1 個與本魔石自身形狀相同的魔石，本魔石基礎屬性提高 x%。
- 固定值基礎魔石範圍：32%～160%。
- 百分比基礎魔石範圍：2%～12%。
- 同形狀數量目前包含本魔石自身。
- 已納入配裝器、單顆比對、自動最佳化與 OCR 潛能候選。

## 2026-08-13 自動最佳化顯示更新
- 保留完整跨魔石連動最佳化，不會錯誤排除非目標屬性魔石。
- 最佳化結果新增每顆魔石「被選入原因」與「對整套的邊際貢獻」。
- 若非目標屬性魔石是因紅色魔石數、形狀、赤曜聚能等連動而被選入，會標示為「連動支援」。
- 面板完全同分時，才以目標屬性直接相關程度作為 tie-break。
